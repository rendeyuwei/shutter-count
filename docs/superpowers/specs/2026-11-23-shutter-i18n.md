English summary: Chinese stays at `{BASE_PATH}/` and English is `{BASE_PATH}/en/`. The mount is runtime configuration (`/shutter/`, `/`, `/tools/counter/`, and any other accepted `BASE_PATH`). Language is only the `en` segment directly after that mount. API, CSS, JS, and the guide image stay on the mount. The inlined `window.rfLang` stays v1. The shared bar at `09687c36` is v2 and refreshes on `rf:locale`. `shutter.en` remains `false` until a later main-site deployment.

## 判定

1. URL：路径在挂载后以 `en` 或 `en/` 开头就是英文。无前缀页带 `lang=zh` 就是中文。二者都不被偏好或浏览器语言覆盖。
2. 手选：只有点击页内开关或共享顶栏开关才写 `localStorage["rf-lang"]`。存储抛错时写 cookie `rf-lang`（`Path=/; Max-Age=31536000; SameSite=Lax`，https 加 `Secure`）。
3. `navigator.languages` 里第一个主标签为 `zh` 或 `en` 的项。`zh-HK`、`zh-TW` 都是中文（简体文案）。
4. 没有匹配：英文。

自动选择只会发生在无前缀且没有 `lang=zh` 的页面，方向只有到 `en/`。英文页不自动返回，所以没有循环。跳转保留 query 和 hash。未声明 `hreflang="en"` 的页面不跳。

挂载是 `/shutter/` 或 `/` 时，直接调用契约的 `enter()`。其他挂载不用契约算出的 `/en/...` 地址，而用同一套判定生成 `{mount}en/`。契约表里的 `en: false` 只影响主站跨站入口，不影响本站 `href()` 和 `offers()`。

## 页面

- `web/index.html` 与 `web/en/index.html`：翻译后的 title、description、可见文案、alt 与 aria。
- `<head>` 内联契约脚本（不带 `data-rf-enter`）和本站判定脚本，位于统计脚本和样式之前。统计脚本看到 `rfLang.leaving` 或 `__SC_LEAVING` 就跳过。
- canonical 使用请求的协议和 Host；Host 不安全时退回配置里的 host 与端口。`x-default` 指向英文。
- 图标、样式和脚本写成 `__SC_MOUNT__` 开头的挂载路径，由服务端按当前挂载替换。`pushState` 改变文档地址后，这些地址不再被重新解析到挂载外面。接口和说明图同样用 `window.__SC_MOUNT`。
- 共享顶栏是 `/shell/topbar.4a304e017601ad56e80a5c39886c186fa462161ce585d093ae92c4cfc17edd7b.js`，并带 `data-tool="shutter"`，不带 `data-home`。这不是页面 URL 上的版本号。页面声明 `<meta name="rf-mount">`，内容是当前挂载（`/`、`/shutter/` 或自定义前缀）。`<meta name="sc-mount">` 仍在。`<head>` 里内联的契约保持 v1，供最早的 `enter()` 使用；在 `/` 和 `/shutter/` 上它与钉住的 lang 判定一致，所以不另请求 `/shell/lang.js`。顶栏脚本带上 v2 后会替换这份内联副本，并且不调用 `enter()`。钉住的顶栏里三个工具的 `en` 是 `true`。HTML 响应是 `Cache-Control: no-cache`；接口和图片缓存不变。
- 已经显示解析结果、失败帮助或错误时，切换语言仍只 `pushState` 一次，然后更新本页文案。若 `rfLang.v >= 2`，接着 `rfLang.choose(next)` 并派发 `rf:locale`。顶栏自己重画整条栏并交还焦点。本页不改顶栏节点的文字或链接，不替换 `place()` 或 `href()`。前进后退只重读 URL，不写偏好。没有顶栏或仍是 v1 时，页内开关继续可用。空的上传页仍按链接整页打开。

## 结果说明

解析规则、品牌优先级和次数上限不变。成功结果增加 `noteCode`：`canon_image_count`、`fuji_image_count` 或 `null`。原来的中文 `note` 保留。解码器忽略未知代码，不把未知字符串显示出来；没有代码时仍显示 `note`。仅有 `approximate: true` 的通用说明仍由页面按语言生成，不改服务端的 `note: null`。

中文缺失帮助仍用未裁剪原截图 `iphone-export-original.jpg`（SOF 1206×1550）。英文用 `iphone-export-original-en.jpg`（SOF 864×1152）。这张图是带来源说明的英文示意图，图内写着 English illustration。英文步骤不再引用中文菜单名。两张图都放在挂载根上，`{mount}en/` 下面不是它们的地址。查看大图打开当前语言的那一张。

## 已接入的外壳契约

外壳源是 `rendeyuwei/rende-site` `fdaa701bbf2736ee2874cfe5456bd25d941145f6`。测试使用这次本地构建的精确字节，不请求尚未公开的哈希 URL。`window.rfLang` 在顶栏加载后是 v2。页面用 `v >= 2` 判断能否派发 `rf:locale`，不要求内联副本也是 v2。`place()` 返回 `mount`。声明了 `rf-mount` 且 `data-tool="shutter"` 时，`/tools/counter/en/` 属于该挂载上的英文。这份顶栏里工具的 `en` 是 `true`，英文页的菜单指向各工具的 `/en/`。本仓库不改主站。
