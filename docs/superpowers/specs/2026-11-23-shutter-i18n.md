# ShutterCount 中英文对齐说明

状态：按 2026-11-23 已批准的四站契约实现，仅预览，不合并、不部署、不改服务器或 ESA。主站规格与契约来自 `rendeyuwei/rende-site` `64701ced2b3e495f8e5237148096a5a665e41c17`：`docs/superpowers/specs/2026-11-23-sites-i18n-design.md`、`src/shell/lang.ts`、`src/shell/topbar.ts`。

English summary: Chinese stays at `{BASE_PATH}/` and English is `{BASE_PATH}/en/`. The mount is runtime configuration (`/shutter/`, `/`, `/tools/counter/`, and any other accepted `BASE_PATH`). Language is only the `en` segment directly after that mount. API, CSS, JS, and the guide image stay on the mount. The page uses vendored `window.rfLang` v1. `shutter.en` remains `false` in that copy; enabling it is a later main-site change.

## 判定

1. URL：路径在挂载后以 `en` 或 `en/` 开头就是英文。无前缀页带 `lang=zh` 就是中文。二者都不被偏好或浏览器语言覆盖。
2. 手选：只有点击页内开关或共享顶栏开关才写 `localStorage["rf-lang"]`。存储抛错时写 cookie `rf-lang`（`Path=/; Max-Age=31536000; SameSite=Lax`，https 加 `Secure`）。
3. `navigator.languages` 里第一个主标签为 `zh` 或 `en` 的项。`zh-HK`、`zh-TW` 都是中文（简体文案）。
4. 没有匹配：英文。

自动选择只会发生在无前缀且没有 `lang=zh` 的页面，方向只有到 `en/`。英文页不自动返回，所以没有循环。跳转保留 query 和 hash。未声明 `hreflang="en"` 的页面不跳。

挂载是 `/shutter/` 或 `/` 时，直接调用契约的 `enter()`。其他挂载不用契约算出的 `/en/...` 地址，而用同一套判定生成 `{mount}en/`。契约表里的 `en: false` 只影响主站跨站入口，不影响本站 `href()` 和 `offers()`。

## 页面

- `web/index.html` 与 `web/en/index.html`：翻译后的 title、description、可见文案、alt 与 aria。
- `<head>` 内联契约脚本（不带 `data-rf-enter`）和本站判定脚本，位于统计脚本和样式之前。统计脚本看到 `rfLang.leaving` 或 `__SC_LEAVING` 就跳过。
- canonical 使用请求的协议和 Host；Host 不安全时退回配置里的 host 与端口。`x-default` 指向英文。
- 图标、样式和脚本写成 `__SC_MOUNT__` 开头的挂载路径，由服务端按当前挂载替换。`pushState` 改变文档地址后，这些地址不再被重新解析到挂载外面。接口和说明图同样用 `window.__SC_MOUNT`。
- 共享顶栏仍是 `/shell/topbar.js`，并带 `data-tool="shutter"`，不带 `data-home`。顶栏初次提供的语言就是本页另一种语言时，本页记住这一枚 `a.rf-lang`，之后每次内存切换和前进后退只更新它的文字、`hreflang` 和链接，并隐藏页内开关。顶栏其余链接保持它第一次画出的语言。本页不替换 `rfLang.place` 或 `rfLang.href`，也不调用尚未公布的刷新方法。
- 已经显示解析结果、失败帮助或错误时，切换语言用 `history.pushState` 留在同一页，按新语言重画当前结果。照片不写入存储，也不再上传。空的上传页仍按链接整页打开。自定义挂载上，顶栏初次提供的语言对不上时，不改那枚开关，页内开关继续可用。

## 结果说明

解析规则、品牌优先级和次数上限不变。成功结果增加 `noteCode`：`canon_image_count`、`fuji_image_count` 或 `null`。原来的中文 `note` 保留。解码器忽略未知代码，不把未知字符串显示出来；没有代码时仍显示 `note`。仅有 `approximate: true` 的通用说明仍由页面按语言生成，不改服务端的 `note: null`。

中文缺失帮助仍用未裁剪原截图 `iphone-export-original.jpg`（SOF 1206×1550）。英文用 `iphone-export-original-en.jpg`（SOF 864×1152）。这张图是带来源说明的英文示意图，图内写着 English illustration。英文步骤不再引用中文菜单名。两张图都放在挂载根上，`{mount}en/` 下面不是它们的地址。查看大图打开当前语言的那一张。

## 还在等主站的契约

`/` 与 `/shutter/` 上，本页已经能反复切换顶栏那一枚语言开关，前进后退后结果和这枚开关都保持正确。顶栏里的返回首页、工具和工具名仍停在第一次绘制的语言。主站正在补一项向后兼容的小改动。本仓库等确切接口后再接，不自造方法，也不改主站。预期是：

1. 同一文档里语言变了之后，顶栏自己重读当前 URL，或接受一次明确的刷新调用，更新返回首页、工具列表、工具名，以及开关的文字和目标。`v` 保持 1。页面继续不替换 `place()` 或 `href()`。
2. `place()` 与 `href()` 承认页面声明的挂载，使 `/tools/counter/en/` 是该挂载上的英文，而不是 `/en/tools/counter/en/`。在此之前，这种前缀继续使用页内开关，真实顶栏保持可见。

## 主站还需要的变更

本仓库不修改 `rende-site`。英文快门页上线并验证后，把主站 `src/shell/lang.ts` 里 shutter 的 `en` 改为 `true` 再发布主站（`v` 保持 1）。在那之前，主站英文页的工具入口仍指向 `/shutter/`。快门自己的页面已经可以切换。
